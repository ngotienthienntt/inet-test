# /optimize

Analyze and optimize the selected code or file for performance and readability.

## Steps
1. Read and understand the current implementation
2. Identify performance bottlenecks or inefficiencies
3. Check for unnecessary complexity or redundancy
4. Apply targeted improvements without changing behavior
5. Summarize what was changed and why

## Rules
- Do not change external behavior — only internals
- Prefer readability over micro-optimizations
- Add a comment only if the optimization is non-obvious
